- Android 로그인 후 탐색을 `오늘·식단·진행·프로필` 적응형 메뉴트리로 이관한다.
- Health Connect 권한 상태·관리 진입·복귀 재조회를 보강한다.
- 백엔드 API, 컨테이너 이미지, 데이터베이스 migration, Azure 환경 변수는 변경하지 않는다. 따라서 이번 태그는 Android Play release만 트리거하며 Azure Container App revision을 새로 만들지 않는다.
