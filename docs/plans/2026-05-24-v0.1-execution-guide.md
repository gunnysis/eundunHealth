## 세션 간 의존성

```
Session 1 ──→ Session 2 ──→ Session 5
  (Backend)    (테스트/CI)    (정리/검증)
                               ↑
Session 3 ──→ Session 4 ──────┘
  (Android)    (탈퇴/버그)
```

- Session 1 → 2: Backend 코드가 있어야 테스트 작성 가능
- Session 3 → 4: AppError가 있어야 회원 탈퇴/리팩토링에서 사용 가능
- Session 5: 모든 세션 완료 후 최종 정리

**Session 1과 3은 병렬 실행 가능** (Backend와 Android가 독립적)
