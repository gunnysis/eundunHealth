## 1. 제품 개요

**은둔헬스(eundunHealth)** 는 PT 트레이너 없이 헬스장에서 혼자 운동하는 사용자를 위한 Android 헬스 앱이다.

사용자의 신체 정보(키, 몸무게, 골격근량, 체지방률)를 기반으로 맞춤형 주간 운동 계획을 자동 생성하고, 운동 완료를 추적하며, 지속적인 운동 동기부여를 위한 배지 시스템을 제공한다.

### 핵심 가치

- **접근성**: 트레이너 없이도 체계적인 운동 계획 제공
- **자동화**: 신체 정보 기반 주간 운동 계획 자동 생성
- **동기부여**: 운동 완료 추적 및 배지 보상 시스템
- **편의성**: Health Connect 연동으로 운동 세션 자동 감지

### 대상 사용자

- 헬스장을 이용하지만 PT를 받지 않는 운동 초~중급자
- 어떤 운동을 해야 할지 모르거나 계획 없이 운동하는 사용자
- 혼자 운동하면서 체계적인 루틴을 원하는 사용자

## 2. 사용자 시나리오

### 2.1. 회원가입 및 로그인

#### 시나리오 A: 신규 사용자 (첫 설치)

```
앱 설치 → Splash 화면 → 로그인 화면
  ├─ [회원가입] → 이메일/비밀번호 입력 → 회원가입 완료 → 자동 로그인
  │   └─ 온보딩 화면 → 신체 정보 입력 → 홈 화면
  └─ [로그인] → 이메일/비밀번호 입력 → 로그인 완료
      ├─ 프로필 있음 → 홈 화면
      └─ 프로필 없음 → 온보딩 화면 → 신체 정보 입력 → 홈 화면
```

**신체 정보 입력 (온보딩)**
| 항목 | 입력 방식 | 범위 |
|------|----------|------|
| 키 (cm) | 슬라이더 + 키보드 | 100 ~ 250 |
| 몸무게 (kg) | 슬라이더 + 키보드 | 30 ~ 200 |
| 골격근량 (kg) | 슬라이더 + 키보드 | 10 ~ 100 |
| 체지방률 (%) | 슬라이더 + 키보드 | 1 ~ 50 |

- 범위 초과 시 빨간색 에러 표시 + 안내 메시지
- 입력 요약 카드로 등록 전 확인 가능
- "운동 계획 받기" 버튼으로 프로필 저장 후 홈 화면 진입

#### 시나리오 B: 기존 사용자 (재방문)

```
앱 실행 → Splash 화면
  ├─ 저장된 세션 있음 → 자동 로그인 → 홈 화면
  └─ 세션 만료/없음 → 로그인 화면 → 이메일/비밀번호 입력 → 홈 화면
```

- Supabase 세션 자동 저장/복원으로 매번 로그인 불필요
- 토큰 만료 시 자동 갱신 (TokenAuthenticator)

### 2.2. 메인 페이지 (홈 화면)

로그인 후 사용자에게 표시되는 메인 화면으로, 주간 운동 계획과 진행 상황을 한눈에 확인할 수 있다.

#### 주간 운동 계획 표시

사용자의 신체 정보를 분석하여 **금주 요일별 운동 계획**을 자동 생성하고 표시한다.

| 요일 | 운동 유형 | 종목 수 |
|------|----------|--------|
| 월 | 근력 운동 (chest, back, shoulders 등) | 4종목 |
| 화 | 유산소 운동 | 2종목 |
| 수 | 근력 운동 | 4종목 |
| 목 | 유산소 운동 | 2종목 |
| 금 | 근력 운동 | 4종목 |
| 토 | 혼합 (근력 2 + 유산소 1) | 3종목 |
| 일 | 휴식일 | - |

#### 오늘 운동 하이라이트

- **오늘 날짜의 요일 카드**를 시각적으로 하이라이트하여 사용자가 오늘의 추천 운동을 즉시 인지할 수 있도록 한다
- 각 요일 카드에 운동명, 부위, 세트/횟수 표시
- 운동명 탭 시 운동 상세 화면으로 이동 (GIF 애니메이션, 운동 방법 안내)

#### 운동 완료 처리

- **수동 완료**: 요일 카드 탭으로 운동 완료/미완료 토글
  - Optimistic update: 즉시 UI 반영, 서버 실패 시 롤백
  - 완료 시 카드 배경색 변경 + 체크 아이콘 표시
- **자동 감지**: Health Connect 연동 시 운동 세션 자동 감지 → 해당 날짜 자동 완료 처리

#### 주간 진행률

- 홈 화면 상단에 주간 완료율 프로그레스 바 표시
- 완료/전체 운동일 수 및 퍼센트 표시

### 2.3. 운동 상세 정보

각 운동의 상세 정보를 확인할 수 있다.

- 운동 GIF 애니메이션 (동작 시각화)
- 운동명, 타겟 부위, 사용 장비
- 세트 x 횟수
- 운동 방법 (단계별 안내)

### 2.4. 운동 기록 히스토리

과거 주간 운동 기록을 확인할 수 있다.

- 무한 스크롤 페이지네이션
- 주별 카드: 날짜 범위, 완료율, 요일별 완료 체크 아이콘

### 2.5. 배지 시스템

운동 지속성을 기반으로 배지를 부여하여 동기부여를 강화한다.

| 배지 | 조건 |
|------|------|
| `week_1_complete` | 첫 주 운동 목표 달성 |
| `week_2_complete` | 2주 연속 목표 달성 |
| `streak_3weeks` | 3주 연속 목표 달성 |

- 운동 계획 로드 시 자동 배지 체크 및 수여
- 획득 배지: 트로피 아이콘 + 획득 날짜 표시
- 미획득 배지: 잠금 아이콘 + 회색 배경

### 2.6. 프로필 관리

- 홈 화면 상단바에서 프로필 편집 화면 진입
- 기존 신체 정보 로드 → 수정 → 저장
- 신체 정보 변경 시 다음 주간 계획에 반영

### 2.7. 테마 설정

- SYSTEM / DARK / LIGHT 3단계 순환 토글
- 앱 재시작 시 설정 유지 (DataStore)
- Material3 Dynamic Color 지원 (Android 12+)

## 5. 기술 아키텍처

### 시스템 구성

```
┌─────────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│   Android App       │────▶│  Backend (Ktor)  │────▶│ Azure PostgreSQL│
│   (Jetpack Compose) │     │  Azure Container  │     │                 │
│                     │     │  Apps             │     │                 │
└────────┬────────────┘     └──────────────────┘     └─────────────────┘
         │
         ├──▶ Supabase Auth (인증)
         ├──▶ ExerciseDB API (운동 데이터)
         ├──▶ Health Connect (운동 세션 감지)
         └──▶ Sentry (에러 모니터링)
```

### Backend API (v0.1.0 — FastAPI Python 3.12)

| Method | Path | 설명 | 도입 |
|--------|------|------|-----|
| `GET` | `/health` | 헬스 체크 | v0.1 |
| `GET` | `/profile` | 프로필 조회 | v0.1 |
| `PUT` | `/profile` | 프로필 생성/수정 (restDay 포함, 매 호출마다 history 자동 기록) | v0.1 / v0.3 |
| `GET` | `/profile/history?limit=50` | 프로필 변경 이력 (체형 진행 차트용) | v0.3 |
| `GET` | `/weekly-plan?week_start=` | 주간 계획 조회 | v0.1 |
| `POST` | `/weekly-plan` | 주간 계획 생성 | v0.1 |
| `PATCH` | `/weekly-plan/complete` | 운동 완료 토글 | v0.1 |
| `GET` | `/weekly-plan/history?page=&size=` | 히스토리 조회 (페이지네이션) | v0.1 |
| `GET` | `/weekly-plan/previous?week_start=` | 직전 주 plan (excludeIds 알고리즘 입력) | v0.2 |
| `GET` | `/weekly-plan/statistics?weeks=12` | 주간 완료율 + 현재/최장 스트릭 | v0.2 |
| `GET` | `/badges` | 배지 목록 조회 (9종) | v0.1 / v0.3 |
| `POST` | `/badges/{key}` | 배지 수여 | v0.1 |
| `GET` | `/goals` | 목표 목록 (체중·체지방) | v0.3 |
| `PUT` | `/goals` | 목표 upsert | v0.3 |
| `DELETE` | `/account` | 회원 탈퇴 (Supabase Auth + 앱 DB 일괄 삭제) | v0.1 |

모든 보호 엔드포인트는 Supabase JWT(ES256 / JWKS) 검증. 응답은 camelCase JSON.

| 인증 상태 모델 리팩터: `SessionState` / `AuthOpState` / `SignupState` | 가입/로그인 실패 시 화면 튕김 + 스낵바 잘림 버그 해소 |
