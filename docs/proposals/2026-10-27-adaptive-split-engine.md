## 1. 배경 및 기획 의도 (Background & Value)

### 1.1 기획 배경
- 선행 기획인 [PROP-01](2026-10-27-flexible-rest-days.md)을 통해 사용자가 원하는 만큼 자유롭게 휴식일을 설정할 수 있는 기반이 마련된다.
- 그러나 사용자의 실제 운동 일수($N = 7 - restDays.size$)가 주 1일에서 주 6일까지 다양해짐에 따라, **"각 운동 일수($N$)에 가장 생리학적으로 적합하고 효과적인 부위별 분할 루틴을 제공해야 한다"**는 전문적인 운동 처방 니즈가 발생한다.
- 예컨대 주 2일만 운동하는 사용자에게는 한 번에 전신을 자극하는 '전신 복합 루틴(Full Body)'이 효과적이며, 주 4일 운동하는 사용자에게는 '상체/하체 2분할'이 가장 최적의 볼륨과 회복을 제공한다.

### 1.2 사용자 가치 (User Value)
1. **전문 트레이너 수준의 맞춤 처방**:
   - 헬스 초보자가 복잡한 분할 이론을 몰라도, 본인이 가능한 요일만 고르면 시스템이 세계 스포츠의학 표준에 부합하는 최적의 분할 방식을 자동으로 설계해 준다.
2. **운동 효율 극대화 및 오버트레이닝 방지**:
   - 동일 부위 연속 운동으로 인한 피로 누적이나 부상을 방지하고, 주간 총 볼륨(Volume)을 운동 일수에 맞춰 과학적으로 배분한다.

## 2. 적응형 분할 매트릭스 상세 설계 (Split Matrix)

실제 운동 일수 $N$에 따른 부위별 분할 전략:

| 운동 일수 ($N$) | 분할 전략 (Routine Strategy) | 부위별 슬롯 구성 (GYM / HOME 공통) |
| :---: | :--- | :--- |
| **주 1~2일** | **전신 고효율 복합 (Full Body Compound)** | • Day A: 가슴 + 등 + 하체 메인 + 코어<br>• Day B: 어깨 + 둔근 + 전신 유산소 + 코어 |
| **주 3일**<br>*(골든 루틴)* | **전통 3분할 (Push / Pull / Legs)** | • Day 1: 가슴 / 삼두 / 전면 삼각근 (Push)<br>• Day 2: 등 / 이두 / 후면 삼각근 (Pull)<br>• Day 3: 대퇴사두 / 햄스트링 / 둔근 (Legs) |
| **주 4일** | **상체 / 하체 2분할 (Upper / Lower)** | • Day 1: 상체 A (가슴·등 위주)<br>• Day 2: 하체 A (스쿼트·둔근)<br>• Day 3: 상체 B (어깨·팔 위주)<br>• Day 4: 하체 B (햄스트링·종아리) |
| **주 5일** | **부위별 4분할 + 전신 유산소 피니셔** | • Day 1: 가슴 + 삼두<br>• Day 2: 등 + 이두<br>• Day 3: 하체 + 코어<br>• Day 4: 어깨 + 승모<br>• Day 5: 전신 인터벌 유산소 / 기능성 운동 |
| **주 6일** | **3분할 2회전 (현행 시스템 유지)** | • Push ➔ Cardio ➔ Pull ➔ Cardio ➔ Legs ➔ Mixed |

## 3. 모드별 특화 알고리즘 (`AdaptiveSplitEngine`)

### 3.1 헬스장 모드 (GYM - ExerciseDB 46종 풀)
- 운동 일수 $N$에 맞는 `Strategy`를 선택하고, 각 카테고리(`push`, `pull`, `legs`, `cardio`)에서 요구되는 종목 수를 동적으로 샘플링.
- $N \le 2$인 경우: 각 카테고리에서 1~2종목씩 추출하여 전신 복합 슬롯 생성.
- $N = 4$인 경우: `upper` 슬롯(`push` 2종 + `pull` 2종)과 `lower` 슬롯(`legs` 3종 + `core/cardio` 1종) 교차 배치.

### 3.2 홈트레이닝 모드 (HOME - 내장 18종 풀)
- 무장비, 층간소음 방지, 체중 부하 중심 18종 카탈로그를 활용:
  - 전신 모드: 푸시업(Push) + 슈퍼맨 홀드(Pull) + 에어 스쿼트(Legs) + 플랭크(Core)의 4종 올라운드 조합.
  - 상/하 2분할: 상체 데이(푸시업/체어딥스/버드독/YTW) ⇄ 하체 데이(스쿼트/런지/브릿지/카프레이즈).

## 4. 타 시스템 연계 및 시너지 (Ecosystem Integration)

### 4.1 AI 식단 프롬프트 고도화 (DeepSeek MaaS)
- 사용자의 운동 일수 $N$과 실제 운동 요일 정보를 AI 식단 프롬프트에 직접 주입:
  ```text
  [사용자 운동 스케줄]
  - 실제 운동 요일: 월요일(상체), 수요일(하체), 금요일(상체) (주 3일 운동)
  - 휴식일: 화요일, 목요일, 토요일, 일요일 (주 4일 휴식)
  
  [식단 생성 지침]
  - 운동일: 근합성을 위해 단백질 비중 강화 및 운동 전후 탄수화물 배치.
  - 휴식일: 활동 대사량 저하를 감안하여 총 칼로리를 10~15% 낮춘 가벼운 회복식 제안.
  ```

### 4.2 진행 통계 및 운동 밸런스 리포트
- 단순히 완료율만 보여주는 것을 넘어, 주간 상체/하체/유산소 수행 비율을 도넛 차트나 레이더 차트로 시각화하는 피드백 제공.
